# Sun Grow Exim

Exact Next.js clone of the live [sungrowexim.com](https://sungrowexim.com/) WordPress theme markup, CSS, and assets.

## Run

```bash
npm install
npm run dev
```

## Notes

- Live HTML/CSS/JS and `wp-content` media are served locally (no hotlinks).
- About / Products / Contact were blank or unavailable on the live site; those pages are rebuilt from WP REST content + shared chrome.
- Basmati Rice, Potato, and Millets HTML on the live site was spam-hijacked; those pages use clean WP REST content with the product layout.
