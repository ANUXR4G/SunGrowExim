# Sun Growexim (Next.js)

Standalone Next.js site with local pages, product content, images, and brand colors (primary `#1928EE`, secondary `#f9931d`). All assets are local — no dependency on an external live website.

## Pages

- `/` Home
- `/about-us`
- `/products`
- `/gallery`
- `/contact-us`
- Product pages: mango pulp, coconut, rice, spices, potato, millets, basmati, non-basmati, fresh/dried ginger

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
